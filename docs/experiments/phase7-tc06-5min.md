# TC-06 5분 조건 — 지속 부하 + DB 지연

- 날짜: 2026-11-12 (같은 조건 2회 실행, 결과 동일 수준)
- 목적: RFP 조건(1,000 msg/s × 5분, DB 지연)에서 메모리 상한과 "해소 후 누락·중복 0"을 확인한다. 이전에는 30초 조건만 측정했다.
- 판정: **미달.** 메모리 상한은 지켰고 중복·예상 외는 0이지만, 누락이 45%다.

## 조건

| 항목 | 값 |
| --- | --- |
| 장비 | AMD Ryzen 5 7500F (6코어 12스레드), RAM 15.8 GB, WSL2 위의 Docker |
| 구성 | testcontainers TimescaleDB·Mosquitto, 앱은 같은 프로세스(`app.Run`). DB 앞에 FaultProxy |
| 부하 | 센서 10개 × 100 msg/s = 1,000 msg/s, 300초 (`E2E_TC06_DURATION=5m`) |
| DB 지연 | 방향당 100 ms (왕복 200 ms), 부하 구간 내내 |
| 앱 | `BatchSize` 300, `FlushInterval` 2 s, `ChannelSize` 600, 테넌트 채널 100 (ADR-0011) |
| 브로커 | `max_inflight_messages 600`, `max_queued_messages 60000`, persistence on |
| 스키마 | migration 000011 (세로 구조), 메시지당 2행 |
| 판정 | `reconcile`. 부하 종료 후 DB 지연을 풀고 최대 10분 대기 |

## 결과

| 항목 | 값 |
| --- | --- |
| 발행(PUBACK 받은 수) | 센서당 약 29,630건, 합계 약 296,000건 |
| 저장 | 센서당 약 16,140건, 합계 약 161,400건 |
| 누락 | 센서당 약 13,490건, 합계 약 134,900건 (45.5%). 10분 대기 후에도 더 늘지 않음 |
| 중복·예상 외 | 0 |
| **브로커 드롭 수** (`$SYS/broker/publish/messages/dropped`) | **134,883** |
| 채널 깊이 최대 | 410 (상한 600) |
| 힙 | 기준 4 MiB, 최대 60 MiB (증가 56 MiB, 기준 256 MiB) |
| 앱 로그 | DB 오류·재시도·연결 끊김 없음 |

누락 합계와 브로커 드롭 수가 일치한다. 앱이 받은 메시지는 모두 저장했고, 잃은 것은 앱에 도달하기 전에 **브로커가 PUBACK 이후 큐 한도 때문에 버린** 메시지다.

## 해석

1. 앱의 백프레셔는 작동했다. 저장이 느려지자 채널이 차고 수신이 느려졌으며 메모리는 상한 안이었다(불변식 2·4).
2. 그러나 막힌 수신은 브로커의 세션 큐(60,000)로 밀려 쌓이고, 입력이 수집 용량보다 오래 많으면 큐가 넘쳐 PUBACK 한 메시지가 사라진다. **백프레셔가 발행 측까지 전달되지 않는 것이 근본 문제다.** TC-17과 같은 현상이다.
3. 용량이 낮은 직접 원인은 DB 지연이다. 배치 한 번이 왕복 여러 번(트랜잭션 시작, INSERT, 커밋)이라 왕복 200 ms에서는 배치 하나가 수백 ms가 걸린다. 합계 저장량 161k는 약 300초 동안 약 540 msg/s로 처리한 것과 비슷한 규모다(관측 기반 추정이며 분리해서 측정하지는 않았다).
4. 30초 조건은 큐 한도 안(30,000건 부족분)이라 통과했다. 경계는 "초과 입력량 > 큐 크기"다.
5. 가로 구조(ADR-0012 이전) 커밋에서의 5분 결과는 측정하지 않았다. 지연이 지배하는 조건이라 구조 차이가 크지 않을 것으로 보지만 확인한 것은 아니다.

## 선택지 (설계 결정이 필요해 구현하지 않았다)

| | 내용 | 비고 |
| --- | --- | --- |
| A | `max_queued_messages` 상향 | 가장 단순. 지연이 계속되면 결국 넘친다. 브로커 메모리(ADR-0011 표) 증가 |
| B | 왕복 수 줄이기·배치 확대 | 용량 자체를 올린다. 지연에 비례해 이득. 쓰기 경로 변경 |
| C | 큐 깊이 사전 경보 | 유실은 막지 못하고 알린다 |
| D | 저장 워커 병렬화 | 불변식 5 변경. 이 프로젝트에서 사용자 확인이 필요 |
