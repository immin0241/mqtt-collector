# Phase 6 실험: sensor_data.tenant_id 재도입 비용 측정

- 목적: ADR-0006이 미뤄 둔 "tenant_id 재도입 여부"의 측정 근거 (조인 비용 vs 중복 저장·FK 비용)
- 코드: `test/experiments/tenant_id_test.go` (`go test -tags experiment -run TenantID -v ./test/experiments`)
- 실행일: 2026-10-24, **1회 실행**

## 조건

| 항목 | 값 |
| --- | --- |
| 환경 | WSL2 단일 호스트, Docker 29.8.0, 메모리 15.8GB. TimescaleDB `latest-pg18` 컨테이너(기본 설정), 앱과 같은 호스트 |
| 데이터 | 테넌트 20 × 센서 25 = 센서 500, 센서당 2,016행(5분 주기 7일), 총 1,008,000행, chunk 1일, 압축 없음 |
| 변형 A | `tenant_id` 컬럼 + 복합 FK `(sensor_id, tenant_id)` + 인덱스 `(tenant_id, sensor_id, time DESC)`. 뷰는 `WHERE tenant_id = app_tenant_id()` (조인 없음) |
| 변형 B | 현재 스키마. 단일 FK + 인덱스 `(sensor_id, time DESC)`. 뷰는 `sensor`와 조인해 `s.tenant_id = app_tenant_id()` |
| 조회 | 테넌트 5 시점(`SET app.tenant_id`), 쿼리당 22회 중 앞 2회 예열 제외 20회, A/B 번갈아 실행, 단일 연결 |
| 쓰기 | 300행 multi-row `INSERT ... ON CONFLICT DO NOTHING` 200회(회당 60,000행), 단일 연결, 4회 반복 중앙값, A/B 순서를 번갈아 실행 |

## 결과

저장 공간 (1,008,000행):

| 변형 | 데이터 | 인덱스 | 합계 |
| --- | --- | --- | --- |
| A tenant_id 재도입 | 81.5 MiB | 100.5 MiB | 182.0 MiB |
| B 현재 | 73.8 MiB | 101.6 MiB | 175.4 MiB |

조회 (뷰 경유):

| 쿼리 | A 중앙값 | A p95 | B 중앙값 | B p95 | B/A |
| --- | --- | --- | --- | --- | --- |
| Q1 센서 1개 최근 1시간 원본 | 0.32 ms | 0.35 ms | 0.33 ms | 0.41 ms | 1.05 |
| Q2 테넌트 전체 최근 24시간 5분 평균 | 5.32 ms | 6.19 ms | 5.99 ms | 6.74 ms | 1.13 |
| Q3 테넌트 전체 7일 행 수 | 4.42 ms | 5.19 ms | 26.48 ms | 28.68 ms | 6.00 |
| Q4 센서 1개 7일 일평균 | 1.24 ms | 1.37 ms | 1.89 ms | 2.44 ms | 1.52 |

쓰기 (60,000행/회): A 22,661 rows/s(중앙값 2.648s), B 23,264 rows/s(중앙값 2.579s). 차이는 약 2.6%로, 1회 실행의 단일 연결 측정에서는 노이즈와 구분되지 않는다.

## 해석

- **쓰기 비용:** 측정 범위에서 유의한 차이가 없다. 복합 FK 검증과 `tenant_id` 컬럼이 쓰기 처리량에 주는 영향은 이 규모에서 보이지 않는다.
- **저장 공간:** 데이터는 약 10% 커지지만(컬럼 4바이트 + 정렬), 인덱스는 거의 같아 합계는 약 4% 증가했다. 압축을 켜면 증가가 더 작을 가능성이 있으나 **측정하지 않았다**.
- **조회:** 센서 하나를 짚는 쿼리(Q1)는 차이가 거의 없다. 테넌트 전체를 훑는 쿼리(Q3)는 조인 때문에 6배, 중간 규모 집계(Q2, Q4)는 1.1~1.5배 느렸다. 모두 절대값이 수십 ms 이하이며, 대시보드 패널 하나 기준으로는 체감되지 않는 수준이다.
- **한계:** 100만 행 단일 규모만 측정했다. 센서·행 수 증가에 따른 격차 곡선, 연속 집계(`sensor_data_1m`)와 압축된 chunk 위의 조회는 측정하지 않았다. 센서의 테넌트가 바뀔 때의 정합성 비용은 측정이 아니라 설계 문제다.
- 이 결과는 결정이 아니라 근거다. 채택 여부는 ADR로 확정한다.
