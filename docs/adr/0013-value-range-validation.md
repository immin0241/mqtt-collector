# ADR-0013: 범위 밖 측정값과 비정상 시각은 격리하고, 범위는 metric 카탈로그에 둔다

- 상태: **채택** (2026-11-12). 정책과 정의 위치는 사용자 결정이고, 시각 허용 구간과 기본 범위는 구현자가 제안한 값이다.
- 관련: ADR-0003(오류 분류, 이 ADR이 미결 항목 두 개를 닫는다), ADR-0012(metric 카탈로그), TC-07, 불변식 1·3·7

## 배경

ADR-0003은 "범위 밖 값"과 "시간 0 payload"를 미결로 남겼다. 스키마에 CHECK 제약이 없어 둘 다 그대로 저장됐고, TC-07의 "범위 밖 → 격리"를 입증할 수 없었다.

## 선택지

| | 내용 | 판단 |
| --- | --- | --- |
| **A** | **영구 오류로 분류해 그 메시지만 `sensor_data_rejected`에 원문 그대로 격리하고 ack** | **채택.** TC-07 기대와 일치하고 불변식 3을 그대로 따른다 |
| B | 저장하되 `quality` 컬럼으로 표시 | 고장 분석에는 유리하지만 스키마 변경과 모든 뷰·집계의 필터 정책이 필요하고 TC-07과 다르다 |
| C | 검증하지 않음 | 가장 단순하지만 TC-07을 입증할 수 없다 |

범위를 어디에 정의할지는 **metric 카탈로그 컬럼**으로 정했다(다른 후보: Go 상수, 센서별 범위). 새 지표 추가가 카탈로그 행 추가로 끝나는 ADR-0012의 방향과 같고 운영 중에 조정할 수 있다.

## 결정

- `metric.min_value`, `metric.max_value` (migration 000012). NULL은 그쪽 무제한이다. `min_value <= max_value` CHECK가 있다.
- 기본값은 기존 센서 상태 판정의 `DefaultRanges`와 같다: tilt ±30°, crack_width 0~50 mm, temperature -40~85 °C. 통합 테스트가 두 정의의 일치를 확인한다.
- 수집기는 기동 시 카탈로그에서 범위를 읽는다(`NewGormStore`). **범위를 바꾸면 재시작해야 반영된다.** 쓰기 경로에 쿼리를 더하지 않으려는 선택이다.
- **정의는 한 곳이다.** 센서 상태 판정(`HealthConfig.Ranges`)도 `store.Ranges()`를 받아 같은 값을 쓴다.
- 검증은 `GormStore.InsertRows` 안에서 DB에 가기 전에 한다. 실패하면 `pgconn.PgError`로 돌려주고, 기존 분류(SQLSTATE 22 = 영구 오류)와 이분법이 그 메시지만 격리 테이블로 보낸다. 격리 행에는 원문 payload, topic, `sensor_id`, `seq`, 오류 코드가 남는다.

| 검증 | SQLSTATE | 규칙 |
| --- | --- | --- |
| 범위 밖 | `22003` (numeric_value_out_of_range) | 메시지의 측정값 중 하나라도 범위 밖이면 **메시지 전체**를 격리한다 |
| 비정상 시각 | `22008` (datetime_field_overflow) | `time`이 2000-01-01보다 이르거나(0, 1970 포함), `received_at`보다 24시간 넘게 미래 |
| 측정값 없음 | `22023` | ADR-0012 |

시각 구간은 제안값이다. 늦게 도착한 데이터(통신 두절 뒤 일괄 전송, TC-14)는 정상이라 과거 쪽은 느슨하게 두었다. 미래 쪽 24시간은 센서 시계 오차를 허용하면서 명백한 오류를 거른다.

## 불변식에 미치는 영향

- **1·3:** 격리된 메시지도 격리 행이 커밋된 뒤에 ack한다. 정상 행은 같은 배치에서 저장된다.
- **7:** 센서 상태 판정은 수신 핸들러에서 하므로 DB 격리와 무관하다. 범위 밖 값이 반복되면 격리되는 동시에 센서는 faulty가 된다.

## 한계

- **범위 밖 값은 시계열에서 사라진다.** 고장 분석에 필요한 값이면 격리 테이블(원문 payload)에서 읽어야 하고 대시보드에는 나오지 않는다. 이 값이 필요해지면 선택지 B를 다시 검토한다.
- 한 메시지의 값 하나만 범위 밖이어도 정상 값까지 함께 격리된다. 메시지가 ack 단위이기 때문이다.
- 범위가 지표 전체에 하나다. 센서별·설치 환경별 범위는 지원하지 않는다.
- 재시작 없이 범위를 바꿀 수 없다.
- 같은 불량 메시지가 재전달되면 격리 행이 중복된다(ADR-0003, 진단용이라 허용).
